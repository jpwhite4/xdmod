There are known security issues with the validation of parameters in Open XDMoD {{ page.version }}. See the XDMoD security advisories page for detailed information. We highly recommend upgrading to Open XDMoD {{site.latest_sw_version}}.

If upgrading to the latest supported version is not an option, then your Open XDMoD instance should be patched as follows:

RPM installs

  1. Download two patch files: 1e9f8d58d5ccfc.patch and 52cb4f2c4c3d60.patch
  2. Apply the first patch: 
    patch -p1 -d /usr/share/xdmod < 1e9f8d58d5ccfc.patch
  3. Apply the second patch: 
    patch -p1 -d /usr/share/xdmod < 52cb4f2c4c3d60.patch
  4. Remove one file 
    rm /usr/share/xdmod/html/controllers/sab_user/assign_assumed_person.php

    patch -p1 -d /opt/xdmod/share < 1e9f8d58d5ccfc.patch
